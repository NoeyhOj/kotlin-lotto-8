# kotlin-lotto-precourse

## 입력 값
- 비상 근무할 월과 시작 요일
  - 콤마(,)로 구분함.
  - 월(숫자), 시작 요일(월, 화, 수, 목, 금, 토, 일)
    - 2월은 28일까지만 있음
- 평일 순번
  - 콤마(,)로 구분함.
  - 월-금 근무자 순서
- 주말 순번
  - 콤마(,)로 구분함.
  - 토, 일, 법정공휴일 근무자 순서

## 공휴일
- 1월 1일: 신정
- 3월 1일: 삼일절
- 5월 5일: 어린이날
- 6월 6일: 현충일
- 8월 15일: 광복절
- 10월 3일: 개천절
- 10월 9일: 한글날
- 12월 25일: 성탄절

## 예외처리
- 올바르지 않은 입력값일 경우 [ERROR] 태그를 앞에 붙임
- 올바른 입력을 줄 때까지 다시 입력 받는다
- 이름은 최대 5글자
- 총 근무자는 35명 이하여야 한다

## 기능
- 근무자가 2번 연속 근무할 수는 없다
