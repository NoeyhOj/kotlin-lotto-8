# kotlin-lotto-precourse
## 목적
간단한 로또 발매기를 구현한다.
## 기능 구분
- 로또 번호 숫자 범위는 1~45까지다.
    - 로또 숫자는 중복되지 않아야 한다.
    - 무작위로 6개를 뽑아야한다.
    - 숫자는 오름차순으로 나열한다.
- 로또 구입 금액을 입력받는다.
    - 입력 금액은 1000 단위로 입력 받는다.
- 당첨 번호 6개를 입력받는다.
    - 구분자는 쉼표(,)를 사용한다.
- 보너스 번호 1개를 입력받는다.
- 사용자가 구매한 로또 번호와 당첨 번호를 비교하여 당첨 내역 및 수익률을 출력하고 게임을 종료한다.
    - 낮은 등수부터 출력한다.
## 예외 상황
- 로또 구입 금액이 1000으로 나눠 떨어지지 않는 경우
- 당첨 번호를 입력할 때 1~45의 숫자와 쉼표(,) 외의 문자를 사용했을 경우
- 당첨 번호를 중복해서 적은 경우
- 보너스 번호를 여러 개 입력한 경우
- 보너스 번호가 입력한 당첨 번호와 중복된 경우
- 예외 상황 시 에러 문구를 출력해야한다. 단, 에러 문구는 “[ERROR]”로 시작해야 한다.
~~~
[ERROR] 로또 번호는 1부터 45 사이의 숫자여야 합니다.
~~~
## 예외 처리
| 상황                           |예외 문장|
|------------------------------|---|
| 입력한 금액이 1000으로 나누어 떨어지지 않을 때 |[ERROR] 로또 구입 금액은 1,000원으로 나누어 떨어져야 합니다.|
| 입력한 당첨 번호가 6자리가 아닐 때         |[ERROR] 로또 번호는 6개여야 합니다.|
| 입력한 당첨 번호가 1~45 범위 밖일 때      |[ERROR] 당첨 번호는 1~45 범위의 숫자여야 합니다.|
| 입력한 당첨 번호가 중복될 때             |[ERROR] 로또 번호는 중복이 없어야 합니다.|
| 입력한 보너스 번호가 1~45 범위 밖일 때     |[ERROR] 보너스 번호는 1~45 범위의 숫자여야 합니다.|
| 입력한 보너스 번호가 입력한 당첨 번호와 중복될 때 |[ERROR] 보너스 번호는 당첨 번호와 중복되지 않아야 합니다.|
## 입출력 예시
~~~
구입금액을 입력해 주세요.
8000

8개를 구매했습니다.
[8, 21, 23, 41, 42, 43] 
[3, 5, 11, 16, 32, 38] 
[7, 11, 16, 35, 36, 44] 
[1, 8, 11, 31, 41, 42] 
[13, 14, 16, 38, 42, 45] 
[7, 11, 30, 40, 42, 43] 
[2, 13, 22, 32, 38, 45] 
[1, 3, 5, 14, 22, 45]

당첨 번호를 입력해 주세요.
1,2,3,4,5,6

보너스 번호를 입력해 주세요.
7

당첨 통계
---
3개 일치 (5,000원) - 1개
4개 일치 (50,000원) - 0개
5개 일치 (1,500,000원) - 0개
5개 일치, 보너스 볼 일치 (30,000,000원) - 0개
6개 일치 (2,000,000,000원) - 0개
총 수익률은 62.5%입니다.
~~~
## 프로젝트 구조
### Main
- model
  - Lotto.kt : 로또 모델이며, 당첨 번호와 구매한 로또를 비교하고 보너스 번호의 유무를 구분하는 메소드를 가지고 있다
  - LottoRank.kt : 당첨된 등수 모델이며, enum class다. 등수를 구분해서 반환해주는 동반 객체를 가진다
- controller
  - InputController.kt : 입력된 값을 예외처리 하고 필요한 타입으로 반환해주는 메소드를 가진다
  - LottoController.kt : view와 model에 연결되어 로또 프로그램을 전체적으로 관리하는 컨트롤러다
- view
  - View.kt : 값을 console에 출력해주는 메소드를 가진다
- Application.kt : main함수를 가지며, LottoController().run()을 실행한다
### Test
- model
  - LottoTest.kt : Lotto class에서 나타날 수 있는 예외를 테스트하고, 값이 제대로 반환되는지 검증하는 테스트 코드다
  - LottoRankTest.kt : LottoRank의 동반 객체가 제대로 반환하는지 검증하는 테스트 코드다
- controller
  - InputControllerTest.kt : 주어진 입력 값에서 예외를 제대로 반환하고, 출력 타입이 정확한지 검증하는 테스트 코드다
  - LottoControllerTest.kt : 로또 컨트롤러의 로직이 제대로 된 값을 반환하는지 검증하는 테스트 코드다
- view
  - ViewTest.kt : 마지막 결과를 반환할 때, 모든 등수에 대해 제대로 결과가 나타나는지 검증하기 위한 테스트 코드다
- ApplicationTest.kt : 통합 테스트 코드다
